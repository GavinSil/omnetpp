# samples/ — Example Simulations

## Purpose

20+ example simulations demonstrating OMNeT++ features. Use these as reference for how simulation models are structured.

| `neddemo/` | NED language features |
| `embedding/`, `embedding2/` | Embedding OMNeT++ in other apps |

## Standard Simulation Structure

Every simulation model follows this pattern:

### NED File (network definition)
```ned
simple Txc1
{
    gates:
        input in;
        output out;
}

network TicToc
{
    submodules:
        tic: Txc1;
        toc: Txc1;
    connections:
        tic.out --> toc.in;
        toc.out --> tic.in;
}
```

### C++ File (module behavior)
```cpp
#include <omnetpp.h>
using namespace omnetpp;

class Txc1 : public cSimpleModule
{
  protected:
    void initialize() override;
    void handleMessage(cMessage *msg) override;
};

Define_Module(Txc1);

void Txc1::initialize()
{
    if (strcmp("tic", getName()) == 0)
        send(new cMessage("msg"), "out");
}

void Txc1::handleMessage(cMessage *msg)
{
    send(msg, "out");
}
```

### INI File (configuration)
```ini
[General]
network = TicToc

[Config Experiment1]
*.tic.sendInterval = exponential(1s)
```

## Build Pattern

Each sample has its own `Makefile` generated by `opp_makemake`. Build with:
```bash
source setenv        # Set up environment
cd samples/tictoc
opp_makemake -f      # Generate Makefile (if needed)
make                 # Build
./tictoc             # Run (or: opp_run -l tictoc)
```
