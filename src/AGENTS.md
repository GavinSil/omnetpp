# src/ — OMNeT++ Core C++ Source

## Subsystem Map

| Directory | Library | Size | Purpose |
|-----------|---------|------|---------|
| `common/` | `oppcommon` | 11MB | Shared utilities (expression parser, file I/O, string utils, JSON/CSV, SQLite, pattern matching) |
| `sim/` | `oppsim` | 2.1MB | Simulation kernel (component model, FES, RNG, statistics, result recording) |
| `qtenv/` | `oppqtenv` | 2.9MB | Qt-based graphical UI (inspectors, canvas renderers, animation, dialogs) |
| `scave/` | `oppscave` | 1.7MB | Result analysis (file manager, loaders, exporters, vector indexing) |
| `nedxml/` | `oppnedxml` | 944KB | NED/MSG parser and compiler (lex/yacc, AST, code gen, validators) |
| `envir/` | `oppenvir` | 708KB | Runtime environment base (config, output managers, startup, eventlog) |
| `eventlog/` | `oppeventlog` | 420KB | Event log processing (parsing, filtering, message dependency) |
| `utils/` | — | 344KB | Build/dev tools (opp_makemake, opp_test, opp_neddoc, etc.) |
| `layout/` | `opplayout` | 268KB | Graph layout algorithms (force-directed, spring embedder, tree embeddings) |
| `cmdenv/` | `oppcmdenv` | 100KB | CLI user interface (7 files) |

## Dependency Graph

```
common ──┬── sim ──── envir ──┬── cmdenv
         │    ↑               └── qtenv ── layout
         │    │
         ├── nedxml ──┘
         ├── scave
         ├── eventlog
         └── layout
```

All subsystems depend on `common/`. `sim/` also depends on `nedxml/`. `envir/` depends on `sim/`. UI layers (`cmdenv/`, `qtenv/`) depend on `envir/`.

## Build Pattern

Each subsystem has its own `Makefile` that:
1. Includes `../../Makefile.inc` (generated by `./configure`)
2. Defines `OBJS_STD` — explicit list of object files
3. Defines `IMPLIBS` — inter-library dependencies (e.g., `-loppcommon$D`)
4. Builds to `$(LIB_PREFIX)opp<name>$D$(LIB_SUFFIX)`

## Code Conventions (Across All Subsystems)

### File Structure
```
//===--- filename.cc - Brief description ---===//
//
//                     OMNeT++/OMNEST
//            Discrete System Simulation in C++
//
//===-------------------------------------------===//
```

### Namespace Pattern
```cpp
// In src/sim/, src/envir/, etc.:
namespace omnetpp {
// ... code ...
}  // namespace omnetpp

// In src/common/:
namespace omnetpp {
namespace common {
// ... code ...
}  // namespace common
}  // namespace omnetpp

// In .cc files:
using namespace omnetpp::common;
```

### Registration Macros
```cpp
Register_Class(cModule);                          // sim/
Register_PerObjectConfigOption(CFGID_..., ...);   // envir/
```

### Include Patterns
```cpp
// Public headers (simulation models use these)
#include "omnetpp/cmodule.h"

// Internal cross-subsystem includes
#include "common/stringutil.h"
#include "common/stlutil.h"

// Within-subsystem includes
#include "envirbase.h"
```

## Key Files Per Subsystem

### sim/ (Kernel)
- `csimulation.cc` — Simulation loop, event scheduling
- `cmodule.cc` — Module lifecycle (2K lines)
- `cmessage.cc` — Message/packet handling
- `ccanvas.cc` — Canvas/figure API (4.1K lines — largest)
- `netbuilder/` — Dynamic NED network building
- `parsim/` — Parallel/distributed simulation (39 files)

### envir/ (Runtime)
- `main.cc` — Entry point (`opp_run`)
- `envirbase.cc` — Base UI class (2.1K lines)
- `startup.cc` — Initialization sequence
- `sectionbasedconfig.cc` — INI file config system
- Output managers: `omnetppscalarfilemanager`, `sqlitescalarfilemanager`, etc.

### qtenv/ (GUI)
- `qtenv.cc` — Main GUI class (3.1K lines)
- `mainwindow.cc` — Main window
- `inspector*.cc` — Module/object inspectors
- `canvasrenderer.cc`, `figurerenderers.cc` — Visualization
- `animationcontroller.cc` — Animation playback

### common/ (Utilities)
- `stringutil.cc/h` — String operations (`opp_isempty`, `opp_streq`, etc.)
- `expression.cc/h` — Expression parser
- `sqlitedatabase.cc/h` — SQLite wrapper
- `fileutil.cc/h`, `filereader.cc/h` — File I/O
- `jsonwriter.cc/h`, `csvwriter.cc/h` — Output formats

### nedxml/ (NED/MSG Compiler)
- `ned2.lex`, `ned2.y` — NED lexer/parser (flex/bison)
- `msg2.lex`, `msg2.y` — MSG lexer/parser
- `msgcodegenerator.cc` — C++ code gen from MSG (1.8K lines)
- `nedcrossvalidator.cc` — NED validation (29 TODOs — most in codebase)

### scave/ (Analysis)
- `resultfilemanager.cc` — Central result file management
- `vectorfileindex*.cc` — Vector file indexing
- `exporter*.cc` — CSV, JSON, OMNeT++ format exporters
