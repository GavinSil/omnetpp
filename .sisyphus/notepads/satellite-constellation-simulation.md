# 卫星星座仿真系统功能描述

> 基于 OMNeT++ 6.4.0 框架，结合 INET、OS³、space_Veins、Atlas 等生态项目

---

## 一、系统定位

本系统是一个**离散事件驱动的卫星星座仿真平台**，支持遥感、通信、算力三类卫星的协同建模与仿真。系统在 OMNeT++ 内核之上，整合轨道动力学、无线信道、网络协议栈、星上计算等能力，提供从物理层到应用层的全栈仿真。

## 三、轨道动力学与星座构型

### 3.1 轨道传播模型

| 模型 | 精度 | 适用场景 | 来源 |
|------|------|---------|------|
| Kepler 两体轨道 | 中 | 理想轨道快速验证 | 自定义轨道模块 |
| SGP4/SDP4 | 高 | LEO/MEO/GEO 真实轨道（NORAD TLE 输入） | OS³ 框架 |
| J2 摄动 | 中 | 长期轨道漂移分析 | 自定义模块 |
| 数值积分（RK4/RKF78） | 极高 | 轨道机动、规避仿真 | 自定义模块 |

**关键参数**：
- 轨道六根数（半长轴、偏心率、倾角、升交点赤经、近地点幅角、真近点角）
- NORAD 两行根数（TLE）文件直接导入
- 仿真时间精度：`simtime_t` 支持 ps 级（固定点 64 位）

**OMNeT++ 支撑**：
- `cSimpleModule` 实现轨道计算模块，`scheduleAt()` 定时更新位置
- 可基于现有示例和轨道传播模块实现 Kepler 轨道快速建模
- OS³ 提供 `SatSGP4Mobility` / `SatSGP4FisheyeMobility` 直接可用

### 3.2 星座构型

| 构型 | 描述 | 参数化方式 |
|------|------|-----------|
| Walker‑δ | 均匀分布星座 | 总星数 T、面数 P、相位因子 F |
| Walker‑star | 极地星座（铱星式） | 面数、每面星数 |
| 玫瑰星座 | 单面/多面倾斜圆轨道 | 倾角、面数、相位 |
| 混合星座 | 多层（LEO+MEO+GEO） | 多组轨道参数 |

**OMNeT++ 支撑**：
- NED 参数化子模块：`satellite[numSats]: Satellite { ... }`
- INI 文件批量配置：`*.sat[*].altitude = uniform(500km, 2000km)`
- 初始化阶段分层构建：`initialize(int stage)` 多阶段初始化

### 3.3 轨道机动

| 能力 | 说明 | 实现方式 |
|------|------|---------|
| 轨道维持 | 位置保持脉冲 | 修改速度矢量参数 |
| 轨道转移 | 霍曼转移/快速转移 | 参数动态变更 + 事件调度 |
| 碰撞规避 | 紧急机动 | 消息驱动状态机 |
| 离轨/退役 | 再入大气层 | 模块动态删除 |

**OMNeT++ 支撑**：
- `handleParameterChange()` 响应运行时参数变更
- `cModuleType::create()` / `deleteModule()` 动态模块管理
- `cFSM` 有限状态机管理轨道段切换

## 四、通信卫星仿真

### 4.1 卫星通信链路建模

#### 4.1.1 链路类型

| 链路类型 | 说明 | 建模要点 |
|---------|------|---------|
| 星间链路 (ISL) | 卫星间通信，分同轨/异轨 | 拓扑动态变化，需频繁重构 |
| 馈电链路 | 卫星↔信关站 | 大容量、定向波束 |
| 用户链路 | 卫星↔终端 | 多波束、频移/时延 |
| 星地测控链路 | TT&C | 低速率、高可靠 |

#### 4.1.2 信道模型

| 特性 | OMNeT++/INET 支撑 | 说明 |
|------|-------------------|------|
| 自由空间损耗 | `cDatarateChannel` + INET `PathLoss` | 距离^2 衰减 |
| 雨衰/大气衰减 | OS³ 天气模型 + ITU-R P.618 | 天气数据导入 |
| 多普勒频移 | 自定义 `cChannel` 子类 | LEO 卫星显著频移 |
| 波束覆盖 | INET 天线增益模型 | 点波束/全球波束 |
| 调制编码 | INET physicallayer 框架 | DVB-S2/DVB-S2X |
| BER/PER | `cDatarateChannel` 内置 | 基于信道 SNR 自适应 |

**关键实现**：
- `cDatarateChannel`：传播延迟 + 数据速率 + BER/PER 信道模型（`SINGLE`/`MULTI`/`UNCHECKED` 模式）
- INET 无线物理层：`IRadioMedium`、`IPathLoss`、`IPropagation` 接口可扩展
- 动态连通性：基于轨道位置和地球遮挡进行视距/非视距切换判定

#### 4.1.3 动态拓扑管理

| 能力 | 实现方式 |
|------|---------|
| 实时连通性检测 | LOS 视距计算（OS³ `SatSGP4` + 地球遮挡） |
| 链路动态建立/拆除 | `handleParameterChange()` + 信道 `disabled` 参数 |
| 路由实时更新 | `cTopology` 运行时快照 + 最短路径 |
| 波束切换 | `cFSM` 状态机 + `scheduleAt()` 定时触发 |

### 4.2 协议栈

| 层次 | 协议/功能 | OMNeT++/生态支撑 |
|------|----------|-----------------|
| 物理层 | DVB-S2/S2X, CCSDS, 自定义 | INET physicallayer 框架 |
| 链路层 | TDMA/FDMA/CDMA/OFDMA | INET MAC 框架 + ComNets TDMA |
| 网络层 | IP, IPv6, CCSDS SPP, DTN | INET IPv4/IPv6 + 自定义 |
| 传输层 | TCP, UDP, SCTP, TP-CCSDS | INET 传输层 |
| 路由 | OSPF/BGP, Dijkstra, 自适应卫星路由 | INET 路由 + `cTopology` |
| 切换管理 | 波束切换、卫星切换 | 自定义 `cFSM` 状态机 |

**生态框架支持**：
- **INET Framework**：完整 IP 协议栈、无线信道模型、路由协议、应用层协议
- **Simu5G**：5G NR 协议栈，可扩展至星地 5G NTN
- **SimuLTE**：LTE/LTE-A 协议，适用于卫星回程

### 4.3 性能指标采集

| 指标 | OMNeT++ 原生支撑 |
|------|-----------------|
| 端到端延迟 | `@statistic` + `cOutVector` 向量记录 |
| 吞吐量 | `@statistic` scalar/vector |
| 丢包率 | 信道 BER/PER + `cResultFilter` |
| 链路可用性 | LOS 信号统计 + `cStdDev` |
| 切换次数/中断时间 | 自定义信号 emit/subscribe |
| 覆盖率 | 地面站可见卫星数统计 |
| 频谱效率 | 调制编码方案 + 带宽统计 |

## 五、遥感卫星仿真

### 5.1 遥感载荷建模

| 能力 | 说明 | OMNeT++ 支撑 |
|------|------|-------------|
| 成像载荷 | 可见光/红外/SAR 传感器模型 | `cSimpleModule` 子类化 |
| 观测条带 | 侧摆角/条带宽度/分辨率 | 参数化配置 |
| 数据量生成 | 原始数据率/压缩比/存储容量 | `cPacket` 建模数据产品 |
| 观测任务调度 | 任务规划/冲突消解 | `cFSM` + `scheduleAt()` |
| 存储管理 | 星上存储有限/数据回传窗口 | `cPacketQueue` 队列建模 |

### 5.2 遥感工作流

```
任务下达 → 轨道计算 → 观测窗口确定 → 侧摆规划 → 成像执行
   → 原始数据生成 → 星上处理(可选) → 存储 → 回传窗口 → 下行
```

**OMNeT++ 建模要点**：
- 观测任务：`cMessage` 子类携带任务参数
- 数据产品：`cPacket` 携带比特长度、时间戳、元数据
- 存储约束：`cPacketQueue` 容量限制 + 溢出策略
- 回传窗口：与通信模块联动，LOS 可见时激活下行链路

### 5.3 覆盖分析

| 能力 | 说明 |
|------|------|
| 重访周期统计 | 遍历网格点，统计卫星可见时间窗口 |
| 地面分辨率计算 | 轨道高度 × 传感器角分辨率 |
| 观测条带重叠分析 | 相邻轨道条带间距计算 |
| 气象约束 | 云覆盖/光照条件对成像影响 |

**OMNeT++ 支撑**：
- 可基于轨道位置和载荷参数计算覆盖范围与重访窗口
- LOS 检测：通过几何关系和地球遮挡进行可见性判定
- 地面网格：`cTopology` + 自定义覆盖统计模块

## 六、算力卫星仿真（星载计算/边缘计算）

### 6.1 星载计算建模

| 组件 | 说明 | OMNeT++ 支撑 |
|------|------|-------------|
| 计算节点 | CPU/GPU/FPGA 资源模型 | `cSimpleModule` 子类化 |
| 任务调度 | 计算任务排队与分配 | `cQueue` / `cPacketQueue` |
| 计算延迟 | 与任务复杂度相关的处理时间 | `scheduleAt()` 延迟建模 |
| 能耗约束 | 太阳能电池板/蓄电池 | 参数 + 信号机制 |
| 存储 | 星上存储容量与读写速率 | `cPacketQueue` 容量约束 |

### 6.2 边缘计算场景

| 场景 | 描述 |
|------|------|
| 星上数据预处理 | 遥感图像压缩/特征提取后下行，减少通信量 |
| 星间协同计算 | 大型计算任务分配到多颗卫星并行处理 |
| 星地协同推理 | 卫星端实时推理 + 地面端复杂模型训练 |
| 算力交易 | 星载算力作为可调度资源的分配与计费 |

**OMNeT++ 建模方式**：
- 计算任务：`cPacket` 子类携带计算量（FLOPs）、数据量、截止时间
- 计算节点：`cSimpleModule`，入队处理，处理时间 = 计算量 / 算力
- 任务卸载：模块间消息传递决策卸载到哪颗卫星或地面
- 联合仿真：COSSIM 框架已验证 GEM5（体系结构）+ OMNeT++（网络）的协同仿真

### 6.3 星地算力协同

```
地面任务中心 → 上行指令 → 卫星A（遥感+计算）
                              ├─ 本地处理 → 结果下行
                              └─ 任务卸载 → 卫星B（算力卫星）
                                              ├─ 本地计算 → 结果回传
                                              └─ 部分卸载 → 卫星C → ... → 地面站
```

## 九、三类卫星的差异化建模

### 9.1 通信卫星

```
关注维度：
├── 链路：带宽、延迟、误码率、切换
├── 路由：星间路由、星地路由、自适应路由
├── 容量：用户容量、频谱效率、多波束管理
└── QoS：延迟、抖动、丢包率
```

**核心模块**：
- 卫星通信节点：继承自 INET `StandardHost` / `WirelessHost`
- 信道模型：`cDatarateChannel` 扩展 + ITU-R 衰减模型
- 路由模块：`cTopology` + 自适应卫星路由
- 切换管理：`cFSM` 波束/卫星切换

### 9.2 遥感卫星

```
关注维度：
├── 观测：条带覆盖、分辨率、重访周期
├── 数据：原始数据量、压缩比、存储容量
├── 回传：下行窗口、数据下行速率
└── 任务：观测规划、优先级、冲突消解
```

**核心模块**：
- 遥感载荷模块：`cSimpleModule`，管理观测条带 + 数据生成
- 数据存储模块：`cPacketQueue` 容量约束
- 回传调度模块：与通信模块联动
- 观测窗口计算：SGP4 轨道 + 地面网格遍历

### 9.3 算力卫星

```
关注维度：
├── 计算：FLOPs 算力、GPU/FPGA 资源
├── 调度：任务排队、优先级、截止时间
├── 能耗：太阳能输入、蓄电池、热约束
└── 协同：星间卸载、星地协同推理
```

**核心模块**：
- 计算节点模块：`cSimpleModule`，处理时间 = 任务FLOPs / 算力
- 任务调度模块：多级队列 + 优先级
- 能耗管理模块：太阳角 + 功耗统计
- 卸载决策模块：延迟/功耗约束下的任务分配

### 9.4 混合星座协同

```
┌───────────────┐     ISL     ┌───────────────┐     ISL     ┌───────────────┐
│  通信卫星 A   │◄──────────►│  算力卫星 B   │◄──────────►│  遥感卫星 C   │
│ (路由/中继)   │             │ (星载计算)    │             │ (观测/成像)   │
└───────┬───────┘             └───────┬───────┘             └───────┬───────┘
        │                             │                             │
        │ 馈电链路                    │ 数据回传                    │ 成像数据
        ▼                             ▼                             ▼
┌───────────────────────────────────────────────────────────────────────────┐
│                           地面站 / 任务中心                              │
└───────────────────────────────────────────────────────────────────────────┘
```

**协同仿真要点**：
- 三类卫星共享同一 `cSimulation` 实例
- `cTopology` 统一管理异构网络拓扑
- 消息传递通过 `cMessage`/`cPacket` 在卫星模块间流转
- 全局时钟 `simtime_t` 保证时序一致

## 十、仿真流程

```
1. 配置阶段
   ├── INI 文件定义星座参数（轨道、数量、载波频段...）
   ├── NED 文件定义网络拓扑（卫星、地面站、链路...）
   └── MSG 文件定义消息格式（观测数据、计算任务、控制指令...）

2. 初始化阶段
   ├── 多阶段初始化（numInitStages）：
   │   ├── Stage 0：读取配置、创建模块
   │   ├── Stage 1：注册卫星/地面站到 ChannelController
   │   └── Stage 2：建立初始链路、启动路由
   └── 轨道传播器启动（SGP4 初始化、TLE 加载）

3. 仿真运行
   ├── 事件循环（cSimulation::run()）
   ├── 卫星位置周期更新（scheduleAt 定时器）
   ├── 链路状态动态更新（LOS 检测、切换触发）
   ├── 消息传输（cMessage/cPacket 在模块间传递）
   └── 信号统计（emit/subscribe 采集性能指标）

4. 结果收集
   ├── 标量/向量/直方图统计自动输出
   ├── Scave 工具链后处理
   └── Python API 自定义分析
```
